# ヒイラギ

欲しい商品と、その商品が売られているページを登録しておくと、
**在庫の復活・希望価格への値下がり・販売開始予定の接近**を定期的に確認して、
アプリの中でお知らせする道具です。

最初のテーマは Mellojoy ですが、**Mellojoy 専用のつくりにはしていません。**
ゲーム機でも、フィギュアでも、限定グッズでも、同じように登録して監視できます。

> **このアプリがやらないこと**
> 自動購入・自動カート投入・決済の代行はしません。CAPTCHA の回避も、
> 販売サイトの制限をすり抜けることもしません。
> 役割は「買えるようになったことを、できるだけ早くお知らせする」ところまでです。
> 購入手続きは、通知から商品ページを開いてご自身で行ってください。

## 友人へ渡すときの説明（そのままコピーして送れます）

1. アプリのURLを開く
2. 「はじめる（アカウント作成）」からメールアドレスとパスワードを登録する
   （確認メールは届きません。そのまま使えます）
3. 「＋ 商品を追加」で欲しい商品の名前を入れる
4. 販売ページを開いて、アドレス（`https://…`）をコピーして貼り付ける
5. 貼り付けた時点で1回目の確認が走り、在庫と価格が表示される
6. あとは放っておけば、在庫が復活したときに「🔔 通知」に届く
7. 通知の「商品ページを開く」を押して、**自分で購入手続きをする**

使い方を先に試したいときは、設定 →「デモデータを用意する」を押してください。
このアプリの中にある練習用の模擬ショップを監視するので、実在の販売サイトには一切アクセスしません。

## 画面

| 画面 | 何をするところ |
| --- | --- |
| ホーム（ダッシュボード） | 登録した商品の「いまの状態」が一覧で並ぶ。買えるものが上に来る |
| 商品を追加 | 商品名・URL・希望価格・販売開始予定を入れる |
| 商品の詳細 | 在庫・価格・監視しているページ・監視履歴・通知履歴・エラーの説明 |
| 通知 | 在庫復活／希望価格／販売開始が近い／取得エラーのお知らせ |
| 設定 | パスワード変更、監視をお休みする時間帯、販売場所、公式アカウント、デモ |
| 管理（管理者のみ） | 利用者・監視対象・実行状況・招待コード |

## 監視のしかた

- 通常は **30分ごと**
- 販売開始予定が近づくと自動的に短くなる（24時間前=10分、1時間前=5分、10分前=1分、直前±=30秒）
- 「監視をお休みする時間帯」を設定すると、その時間は3時間ごとまで広がる
  （販売開始予定がある商品は、お休み時間でも予定を優先します）
- 販売サイトごとに**最短間隔**を決めてあり、それより短くはアクセスしません
- `robots.txt` で禁止されているページは監視しません
- Amazon・メルカリは利用規約で自動巡回が禁止されているため、登録できません
- **同じ商品ページを複数人が登録しても、外部サイトへのアクセスは1回だけ**にまとめ、
  結果を全員に配ります

判断できないときは「状態不明」と表示します。**在庫なしと決めつけません。**

## ローカルで動かす

```bash
npm install
cp .env.example .env.local   # 値を入れる（SETUP.md 参照）
npm run migrate              # データベースの表を作る
npm run serve                # ビルドして http://localhost:3600 で起動
```

`npm run dev` ではなく `npm run serve` を使ってください（OneDrive 配下だと
`next dev` は画面ごとの初回表示に時間がかかり、壊れているように見えます）。

その他のコマンド:

```bash
npm test        # 判定ルール・監視間隔・robots.txt の解釈をテストする
npm run lint    # コードの書き方をチェックする
npm run build   # 本番用にビルドする
```

## 中身の地図

```
src/
  app/                  画面（Next.js App Router）
    (app)/              ログインが必要な画面
    demo/shop/          練習用の模擬ショップ（実在しません）
    api/cron/check/     定期監視の入口（合言葉が必要）
  server/
    monitor/            監視のしくみ
      url.ts            URLの検証と正規化
      adapters.ts       販売サイトごとのルール（ここに1件足せば新サイト対応）
      extract.ts        HTMLから題名・meta・JSON-LDを取り出す
      analyze.ts        在庫と価格の判定（判断できなければ状態不明）
      robots.ts         robots.txt の解釈
      fetcher.ts        ページの取得（時間制限・大きさ制限・転送先の確認）
      schedule.ts       次にいつ見るかを決める
      runner.ts         1回のチェックと通知づくり
    actions/            画面からの操作（サーバー側で実行）
    targets.ts          「商品発見」と「商品監視」をつなぐ入口
  lib/                  DB接続・ログイン・書式・型
db/schema.sql           テーブル定義
.github/workflows/      5分ごとに監視を呼ぶ設定
```
